Moving-window calculation parameters

Common settings for Section 4.5 (Figs. 4.6-4.9):
- Input: processed_data/stanford_vi_e_z62_2d.txt
- Complete 75 x 100 grid containing 7,500 porosity values
- Fourth-order local HOSC cumulant evaluated on complete windows only
- Unit moving step; output is written at complete window centers
- Value weighting uses a Gaussian kernel in porosity-value space
- The high-porosity threshold used for the F1 and contrast metrics is 0.25
- Quantitative metrics were calculated from unclipped local-statistic maps
- Percentile clipping at the 2nd and 98th percentiles was used only for visualization

Fig. 4.6, unweighted and weighted comparison:
- Unweighted baseline: 3 x 3 windows; zero-first-order-moment option enabled
- Weighted main case: 3 x 3 windows, reference porosity 0.26, bandwidth 0.08, normalized weights, zero-first-order-moment option enabled

Fig. 4.7, parameter sensitivity:
- All cases use complete 3 x 3 windows, normalized value-Gaussian weights, and the zero-first-order-moment option
- Reference porosity 0.26, bandwidth 0.08
- Reference porosity 0.27, bandwidth 0.08
- Reference porosity 0.28, bandwidth 0.10

Fig. 4.8, normalization comparison:
- Unweighted baseline compared with a non-normalized value-weighted sum
- The current manuscript does not report the reference porosity and bandwidth for the non-normalized panel; they are therefore not assigned here

Fig. 4.9, window-size and first-order-term comparison:
- Unweighted baseline: complete 3 x 3 windows
- Weighted 3 x 3 case: reference porosity 0.28, bandwidth 0.03, normalized weights, zero-first-order-moment option disabled
- Unweighted baseline: complete 11 x 11 windows
- Weighted 11 x 11 case: reference porosity 0.26, bandwidth 0.04, normalized weights, zero-first-order-moment option disabled

Fig. 4.11, three-dimensional moving-window calculation:
- Input: processed_data/stanford_vi_e_z10_z21_3d_full.txt
- Complete 75 x 100 x 12 grid
- Fourth-order local HOSC cumulant
- Complete 5 x 5 x 3 windows, unit moving step
- Full windows only; the complete input contains no missing samples; output is written at window centers
- Output support: 71 x 96 x 10 = 68,160 window centers
- Value-weighted case: normalized value-Gaussian weights, reference porosity 0.28, bandwidth 0.04, zero-first-order-moment option enabled
- F412_unweighted_avl_fullwindows, F412_unweighted_bell_fullwindows, and F412_weighted_fullwindows are the corresponding calculation outputs
- The current Fig. 4.11 image is archived under figures/from_Paper.docx; see figure_index.txt for its file mapping
