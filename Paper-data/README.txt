Supporting data for "An integrated SGeMS plugin for computing high-order spatial statistics"

Current result packages

supplementary_data_s1/README.md is the entry point for the current manuscript's Supplementary Data S1, synchronized on 2026-11-02. It includes the complete table-to-file and figure-to-file mappings, full-precision Supplementary Tables S1-S11, and the selected-window evidence and reproducibility scripts for manuscript Fig. 8/Table 4 and Supplementary Table S11/Fig. S16. The original archive filename is retained; its current bytes and revision are identified by archive_manifest.json. Python Paper-data/tools/verify_supplementary_data.py verifies the archive and all member checksums.

current_results/2026-10-12/README.md is the entry point for the curated October 2026 results supporting Sections 4.3-4.6 and the conditional marginal/tail-shape supplement. It records the source run IDs, statistical interpretation, selected tables and figures, provenance hashes, and reproduction requirements. The package contains 234 exact copies from completed source runs, together with compact row selections for the representative figures.

Section 4.3 contains Bell/AVL performance and agreement measurements. Sections 4.4-4.6 contain directional-template results, direct moving-window statistics, weighting comparisons, bootstrap intervals, and supporting checks. Sections 4.5 and 4.6 use the direct-statistics protocol recorded in the current run. Historical classifier/OOF protocols and smoke runs are not sources for this result package.

The October result snapshot remains the recorded source-run package. Its older figure previews retain their original filenames and are distinguished from the current manuscript display versions by the Supplementary Data S1 figure map.

Formats and provenance

Numerical summaries use CSV; configurations, gates, and manifests use JSON; figure previews use PNG. Coordinates and support definitions must be interpreted using the metadata of the corresponding run. Source-data provenance and preprocessing are described in raw_data/README.txt and the current result package.
